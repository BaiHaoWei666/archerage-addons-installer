# InfoTracker v2（资讯追踪）

合并 infotracker 与 choretracker：
- 项目与判定沿用 infotracker（任务用 ID 池 + 上限，不分阵营都能计入；角色信息、今日净收入、副本建队也照原版）
- 操作方式参考 choretracker（勾选、排序、展开、悬浮小窗）

## 分类
| 分类 | 项目 | 悬浮窗操作 |
|---|---|---|
| 每日 / 生活 / 周常 / 其他 | 任务组 `[~] 鲸鱼 (2/6)` | 单击展开 / 收起任务清单 |
| 每日挑战 | 活动中心的每日挑战 7 格（名称用任务名；红 = 未开启、橙 = 进行中、绿 = 已完成） | 特产挑战单击展开 / 收起制作材料（`材料名 x数量`）；**双击**材料会打开拍卖场并查询该材料；悬浮窗里特产挑战不显示开头的 `[特产-东部]` |
| 角色信息 | 国王雕像Buff、时装、内衣、多鲁时装、每日任务、公会任务 | — |
| 今日净收入 | 经验、金币、生活点、荣誉（每天自动归零） | — |
| 副本 | 其他副本 7 个 + 英雄副本 7 个 `名称 [已进入/上限]` | **双击**跳出询问窗（可勾选「邀请队伍成员」，会记住上次的选择），确定后建立战队（能单人先快速匹配，失败再建非公开战队；冷却 5 秒；过程输出到聊天框） |

特产挑战的配方：任务目标文字的原始内容是「制作@ITEM_NAME(31844)。」，用其中的物品编号对应 `specialty_data.lua` 里配方的产品编号（与语系无关），所以挑战要先开启（进入任务日志）才能展开；对到后本次登入会记住。

颜色：红 = 未开始 / 有问题，橙 = 进行中，绿 = 已完成 / 正常，白 = 数值。

## 使用
- **悬浮小窗**：常驻画面，按分类分页，只显示该页已追踪的项目。固定大小，内容超出时用右侧卷轴或滑鼠滚轮卷动。
  - 标题栏常驻，显示目前分类。
  - 鼠标移到小窗上时，标题栏出现左右切页箭头与齿轮（打开设定窗口，并切到同一个分类）。
  - **单击标题**：在标题下方展开分类选单（目前分类绿色），点选直接切换；滑鼠离开小窗时自动收起。
  - **Shift + 左键**拖动标题栏可移动小窗（本体不能拖），目前页、位置、高度会存档。
- **设定窗口**：固定大小，清单超出时卷动。八个页签（七个分类 + 面板设定）
  - 最前面的勾选框：是否在悬浮窗追踪
  - 上 / 下箭头：调整在小窗里的顺序
  - 点名称展开 / 收起：任务组列出池子里的所有任务（同名合并成一行）；特产挑战列出制作材料
  - 「本页全部追踪」：把目前页签的项目全部加入追踪
  - 「重置今日收入」：只在今日净收入页出现
  - 面板设定 › 页面：每个分类一个勾选框（预设全开）与上下箭头；关掉的分类不会出现在悬浮窗切页里（至少留一个），顺序同时决定设定窗口页签与悬浮窗切页的顺序
  - 面板设定 › 外观（－／＋ 调整，会存档）：
    | 项目 | 预设 | 范围 | 每次 |
    |---|---|---|---|
    | 悬浮窗高度 | 300 | 100–800 | 20 |
    | 悬浮窗宽度 | 240 | 200–500 | 10 |
    | 标题字体 | 14 | 10–24 | 1 |
    | 主项字体 | 14 | 10–24 | 1 |
    | 细项字体 | 12 | 8–22 | 1 |
    | 背景不透明度 | 80% | 0–100% | 10% |
    行高会跟着字体变（主项 = 字体 + 8，细项 = 字体 + 6，标题栏至少 26）。
- 第一次使用，以及之后版本新增的项目，预设都会追踪。

## 文件
载入顺序见 `toc.g`。所有模组挂在全域表 `ITV2` 底下（清单见 `core.lua` 开头）。

| 文件 | 内容 |
|---|---|
| `core.lua` | 命名空间 `ITV2`、聊天输出、状态符号、`ITV2.RefreshAll()` |
| `locale.lua` | 中英文文字 `ITV2.Text(key)` |
| `quest_data.lua` | 分类与项目清单（任务 ID 池、上限、副本位置、挑战格子） |
| `specialty_data.lua` | 特产配方编号、不能上拍卖的材料编号 |
| `sources/common.lua` | 来源介面说明、共用函数（进度状态、任务名称、任务日志索引） |
| `sources/quest.lua` | 任务组（含同名合并、核对用 Dump） |
| `sources/assignment.lua` | 每日挑战 |
| `sources/specialty.lua` | 特产挑战 → 配方 → 材料、拍卖场查询 |
| `sources/info.lua` | 角色信息 |
| `sources/income.lua` | 今日净收入（事件累计、依角色存档） |
| `sources/dungeon.lua` | 副本次数与建立战队 |
| `items.lua` | 项目索引，安全呼叫来源（出错不中断刷新） |
| `settings.lua` | 设定状态与存档（追踪、顺序、页面、面板外观、位置） |
| `windows/widgets.lua` | 共用 UI 元件（按钮、勾选框、对话视窗、卷动区域） |
| `windows/editor.lua` | 设定窗口 |
| `windows/squad_confirm.lua` | 建立战队询问窗 |
| `windows/popout.lua` | 悬浮小窗 |
| `main.lua` | 进入点：读取设定、显示悬浮窗 |
| `common/` | 从 infotracker 复制的通用函数（`CreateEmptyWindow` 等） |

常见修改：
- 新增任务 / 项目：`quest_data.lua` 加项目，`locale.lua` 中英文都加同名文字 key。
- 新增一种来源：`sources/` 新增档案实作 `ITV2.SOURCES[kind]`（介面见 `sources/common.lua`），并加进 `toc.g`。
- 新增细项的点击动作：来源的 `Children` 回传 `action`，一律双击才执行。

存档：设定 `itv2_settings`；净收入依角色 `itv2_income_<角色名>`。窗口名称皆以 `itv2` 开头，可与 infotracker、choretracker 同时启用。

核对任务合并结果：把 `windows/editor.lua` 的 `SHOW_DUMP_BUTTON` 改成 `true`，任务页会出现「输出本页ID」。
