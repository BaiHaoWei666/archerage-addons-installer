# InfoTracker v2（資訊追蹤）

以 infotracker 的部分程式與功能為基礎延伸開發，僅參考 choretracker 的 UI 操作概念：

- 項目與判定沿用 infotracker（任務用 ID 池 + 上限，不分陣營都能計入；角色資訊、今日淨收入、副本建隊也照原版）
- 對 choretracker 僅參考 UI 操作概念（勾選追蹤、上下排序、展開明細、懸浮小窗）；UI 使用遊戲內建 API 與元件樣式實作。

infotracker 原作者：**Discord @Nevermore (奈奈呀)**。依作者同意，本插件維持原始碼公開、免費使用；本專案只為新增或修改部分署名。授權原話、衍生功能對照與 choretracker 概念參考說明，見 [版權、來源與授權說明](COPYRIGHT.md)。

## 分類

| 分類 | 項目 | 懸浮窗操作 |
|---|---|---|
| 每日 / 生活 / 週常 / 其他 | 任務組 `[~] 鯨魚 (2/6)` | 按一下展開 / 收起任務清單 |
| 每日挑戰 | 活動中心的每日挑戰 7 格（名稱用任務名；紅 = 未開啟、橙 = 進行中、綠 = 已完成） | 特產挑戰按一下展開 / 收起製作材料（`材料名 x數量`）；**按兩下**材料會開啟拍賣場並查詢該材料；懸浮窗裡特產挑戰移除分類前綴 |
| 角色資訊 | 國王雕像Buff、時裝、內衣、多魯時裝、每日任務、公會任務 | — |
| 今日淨收入 | 經驗、金幣、生活點、榮譽（每天自動歸零） | — |
| 副本 | 其他副本 7 個 + 英雄副本 7 個 `名稱 [已進入/上限]` | **按兩下**跳出詢問窗（可勾選「邀請隊伍成員」，會記住上次的選擇），確定後建立戰隊（能單人先快速配對，失敗再建非公開戰隊；冷卻 5 秒；過程輸出到聊天框） |

特產挑戰一律以名稱尋找配方，不依賴任務日誌或目標物品 ID：先比對去除分類前綴後的完整名稱；中文名稱不同時，再將「地區的特產種類」與產品的「[地區簡稱]特產種類」比對。地區簡稱須為任務地區的開頭，特產種類須完全一致，只有唯一相符的配方才能展開。配方名稱索引與材料資料會快取，任務配方結果不另存快取；重新載入後仍使用相同比對流程。

顏色：紅 = 未開始 / 有問題，橙 = 進行中，綠 = 已完成 / 正常，白 = 數值。

每日新增「伊福尼爾」（調查浮空島、調查轉移現象）及「大象＋大樹」（雪原統治者麥默圖斯、黑森林統治者哈拉林特）兩組，各追蹤兩個任務。

## 使用

以下以繁體中文說明操作；遊戲內實際顯示的中文文字使用簡體中文。

- **懸浮小窗**：常駐畫面，按分類分頁，只顯示該頁已追蹤的項目。固定大小，內容超出時自動顯示右側捲軸，可用捲軸或滑鼠滾輪捲動，不需滑鼠移入。
  - 標題列常駐，顯示目前分類。
  - 滑鼠移到小窗上時，標題列出現左右切頁箭頭與齒輪（開啟設定視窗，並切到同一個分類）。
  - **按一下標題**：在標題下方展開分類選單（目前分類綠色），點選直接切換；滑鼠離開小窗時自動收起。
  - **Shift + 左鍵**拖曳標題列可移動小窗（本體不能拖），目前頁、位置、高度會存檔。
- **設定視窗**：固定大小，清單超出時捲動。各分類頁籤及面板設定
  - 最前面的勾選框：是否在懸浮窗追蹤
  - 上 / 下箭頭：調整在小窗裡的順序
  - 點名稱展開 / 收起：任務組列出池子裡的所有任務（同名合併成一行）；特產挑戰列出製作材料
  - 「本頁全部追蹤」：把目前頁籤的項目全部加入追蹤
  - 「重置今日收入」：只在今日淨收入頁出現
  - 面板設定 › 頁面：每個分類一個勾選框（預設全開）與上下箭頭；關掉的分類不會出現在懸浮窗切頁裡（至少留一個），順序同時決定設定視窗頁籤與懸浮窗切頁的順序
  - 面板設定 › 外觀（－／＋ 調整，會存檔）：

    | 項目 | 預設 | 範圍 | 每次 |
    |---|---|---|---|
    | 懸浮窗高度 | 260 | 100–800 | 20 |
    | 懸浮窗寬度 | 220 | 200–500 | 10 |
    | 標題字型 | 15 | 10–24 | 1 |
    | 主項字型 | 14 | 10–24 | 1 |
    | 細項字型 | 13 | 8–22 | 1 |
    | 背景不透明度 | 60% | 0–100% | 10% |

    行高會跟著字型變（主項 = 字型 + 8，細項 = 字型 + 6，標題列至少 26）。
- 第一次使用，以及之後版本新增的項目，預設都會追蹤。

## 更新與效能

- 懸浮窗每 5 秒更新資料；設定視窗顯示時每秒更新目前分類，靜態面板設定頁不定時重新整理。
- 滾輪與捲軸只重排已取得的內容，不重新查詢遊戲資料；文字、顏色及位置未變時略過重複寫入。
- 懸停每至少 75 毫秒檢查一次，只檢查可見列，保留離開後約 400 毫秒的隱藏延遲。
- 任務狀態與每日挑戰資訊只在同次重新整理內快取，下次重新整理重新查詢，避免狀態過期。
- 拍賣查詢按需延遲 300 毫秒執行；建隊冷卻使用共用時鐘的到期時間，不逐幀輪詢全部來源。
- 收入保留即時保存；零變動略過寫入，跨日歸零與當筆收入合併成一次保存。
- `tests/infotracker2_performance_*.lua` 以模擬 API 計算查詢與 UI 寫入次數；不代表遊戲實際 FPS 或耗時量測。

## 檔案

載入順序見 `toc.g`。所有模組掛在全域表 `ITV2` 底下（清單見 `core.lua` 開頭）。

| 檔案 | 內容 |
|---|---|
| `core.lua` | 命名空間 `ITV2`、聊天輸出、狀態符號、`ITV2.RefreshAll()` |
| `locale.lua` | 中英文文字 `ITV2.Text(key)` |
| `quest_data.lua` | 分類與項目清單（任務 ID 池、上限、副本位置、挑戰格子） |
| `specialty_data.lua` | 特產配方編號、不能上拍賣的材料編號 |
| `sources/common.lua` | 來源介面說明、共用函式（進度狀態、任務名稱、任務日誌索引） |
| `sources/quest.lua` | 任務組（含同名合併、核對用 Dump） |
| `sources/assignment.lua` | 每日挑戰 |
| `sources/specialty.lua` | 特產挑戰 → 配方 → 材料、拍賣場查詢 |
| `sources/info.lua` | 角色資訊 |
| `sources/income.lua` | 今日淨收入（事件累計、依角色存檔） |
| `sources/dungeon.lua` | 副本次數與建立戰隊 |
| `items.lua` | 項目索引，安全呼叫來源（出錯不中斷重新整理） |
| `settings.lua` | 設定狀態與存檔（追蹤、順序、頁面、面板外觀、位置） |
| `windows/widgets.lua` | 共用 UI 元件（按鈕、勾選框、對話視窗、捲動區域） |
| `windows/editor.lua` | 設定視窗 |
| `windows/squad_confirm.lua` | 建立戰隊詢問窗 |
| `windows/popout.lua` | 懸浮小窗 |
| `main.lua` | 進入點：讀取設定、顯示懸浮窗 |
| `common/` | 從 infotracker 複製的通用函式（`CreateEmptyWindow` 等） |

常見修改：

- 新增任務 / 項目：`quest_data.lua` 加項目，`locale.lua` 中英文都加同名文字 key。
- 新增一種來源：`sources/` 新增檔案實作 `ITV2.SOURCES[kind]`（介面見 `sources/common.lua`），並加進 `toc.g`。
- 新增細項的點選動作：來源的 `Children` 回傳 `action`，一律按兩下才執行。

存檔：設定 `itv2_settings`；淨收入依角色 `itv2_income_<角色名>`。視窗名稱皆以 `itv2` 開頭，可與 infotracker、choretracker 同時啟用。

核對任務合併結果：把 `windows/editor.lua` 的 `SHOW_DUMP_BUTTON` 改成 `true`，任務頁會出現「輸出本頁ID」。
